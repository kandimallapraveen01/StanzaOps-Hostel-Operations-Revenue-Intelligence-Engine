# StanzaOps Dashboard Documentation

Dashboard Name:
StanzaOps: Hostel Operations & Revenue Intelligence Dashboard

# Page 1: Executive Overview

## Purpose

Provides a summary of hostel performance
using key business KPIs.

## KPI Measures

### Total Residents

Definition:
Total number of registered residents.

Formula:

COUNT(Resident_ID)

Value:
10,000

### Total Revenue

Definition:
Total amount collected from residents.

Formula:

SUM(Amount_Paid)

Value:
70M
